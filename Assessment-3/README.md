# Assessment 3 - Joins (Very Important)

## Objective

To understand and implement SQL Joins using Python and SQLite.

## Database

company_db

### Tables

#### employees

| Column | Type |
|----------|------|
| emp_id | INT |
| emp_name | VARCHAR(50) |
| dept_id | INT |
| salary | INT |

#### departments

| Column | Type |
|----------|------|
| dept_id | INT |
| dept_name | VARCHAR(50) |

---

## Topics Covered

- INNER JOIN
- LEFT JOIN
- GROUP BY
- HAVING
- Aggregate Functions

---

## Tasks

1. Display employee name with department name.
2. Display employees earning more than 50,000.
3. Display department-wise total salary.
4. Display departments with more than 2 employees.
5. Display employees without a department.

---

## Technologies Used

- Python 3
- SQLite3
- Visual Studio Code
